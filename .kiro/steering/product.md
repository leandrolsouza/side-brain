# Product: SideBrain

SideBrain is a desktop productivity app that acts as a "second brain" for organizing work notes. Users capture free-text throughout their day, and AI automatically categorizes entries into projects, classifies by type/status, and rewrites for clarity.

## Core Features

- Quick Capture — free-text input auto-categorized by AI into projects, entry types, and action items
- Projects & Entries — entries organized by project with customizable types (information, decision, request, idea, blocker, update) and action statuses
- Review Inbox — AI suggestions go through a review workflow (auto-approved, pending, approved, corrected)
- Task Kanban — tasks derived from entries with statuses (todo, in-progress, waiting, done)
- Daily Digest — AI-generated summary with overdue tasks, previous day activity, and suggestions
- Smart Chat — conversational AI with context from user data
- Meetings — meeting mode for note capture with AI processing
- Connections — visual graph of relationships between entries and projects
- Reports — productivity insights and activity reports
- AI Usage Dashboard — API consumption and cost tracking
- Auto-update via GitHub Releases
- Automatic SQLite database backup

## Language

The UI and user-facing text is in Brazilian Portuguese (pt-BR). Code, comments, and documentation may be in English or Portuguese.
